- Cyber Power 是面向任何正确接入 NI EnergyLogger 的 FRC 队伍的浏览器端 `.wpilog` 能量分析工具；兼容性只由 WPILOG 1.0 与 EnergyLogger 数据契约决定，不按队号、ProjectName、赛季或固定子系统列表判断。
- 项目治理使用 `ni-github-repo`、`ni-memory` 与项目级 `cyber-power-log-analysis`。
- 日志在浏览器 Web Worker 内解析，服务端与 Vercel 不接收原始日志、解析结果或分析区间；真实私有金标日志不进入 Git。
- Web 应用完全匿名使用，不保留飞书、Supabase、账户、session 或权限验证链路。
- NI Corporate Vercel 项目 `cyber-power` 使用 React Router 与 Node 22，Git Integration 跟踪 GitHub `main`；`https://power.team8214.com` 始终指向最新 Ready production deployment。
- 分析界面固定为“整机 / 电池 / 子系统 / 电机 / 模拟 / 数据质量”六页：整机为总指标、独立图例 Card，以及分别位于独立 Card 的总电流、总功率、累计能量三图；电池电压图集中到电池页，纵轴固定为 `3–13.5 V`，并继续共享时间范围、固定/悬停游标和 AUTO/TELEOP/BROWNOUT 背景；顶部“有效持续时间”在 Enabled 可用时排除 Disabled，缺失 Enabled 时回退完整选区；电池页只对 V2 展示整机口径的电压表现、局部等效压降代理和电压－电流 `dt` 加权分箱分布，两处阈值图例统一命名为“Brownout 电压”，分布主图显示加权中位数与 P25–P75、底部显示观测时长，原始点默认关闭且不连线；不单列负载阶跃、Robot Mode 条件统计或限制说明，也不输出纯内阻、SOC、容量、整机总 Wh 或反事实；子系统为“能量占比”、独立功率/电流/能量图和唯一默认折叠的“明细”，V2 状态作为顶层总行的子行且不得覆盖原总指标；电机页按 Manifest 的 Leader/Follower 关系展示估算效率、`dt` 加权有效覆盖率、同工况铜耗和减速比建议，但不显示冗余页内标题、不绘制覆盖率曲线，独立 Leader 不重复显示自己的名字，计算原理逐行说明并使用 MathML 渲染公式；模拟页配置区左上角显示“明细”，说明问号紧随标题，只显示 Supply Current 配置与报告，不绘制专用图表、不改变原图表；数据质量左侧直接显示日志事实且不显示“可信日志范围”标题，右侧显示验证结果。
- 未读取日志、解析中或替换文件后的浏览器标题只显示 `cyber-power`；分析完成后采用“当前导航页名 | cyber-power”，并随“整机 / 电池 / 子系统 / 电机 / 模拟 / 数据质量”导航实时切换。
- 所有时间序列图共享同一固定游标、悬停临时预览、时间范围与 AUTO/TELEOP/BROWNOUT 背景：悬停只覆盖图表显示，移出恢复固定值，只有图表点击、底部游标操作或峰值定位提交固定值。默认范围按 Practice AUTO、非 Practice AUTO、非 Practice 有效模式的顺序选起点，并以最后有效模式结束，端点在拖动时吸附 Robot Mode 边界。底部 fixed 组件是唯一范围拖动入口，标准 Teleop 显示为 TELEOP，无法推断具体模式的 generic enabled 保留 ENABLED，并在每次 Brownout 开始时刻按完整日志坐标绘制固定像素红色叉号；图表不接管页面滚轮，电压图包含 Brownout 阈值线，峰值功率/电流卡可定位到精确时间且不会改变当前导航页。
- 解析器支持旧版 EnergyLogger 用单个尾随 `/` 标记聚合节点；前导/重复分隔符、中间空段、尾随连字符和规范化冲突仍必须 fatal，仅最后一条不完整 record 可降级恢复。
- Driver Station 模式使用标准 AdvantageKit 的 Enabled、Autonomous、Test 与 int64 MatchType；Teleop 由三项布尔状态推导，MatchType 仅在原始值变化时切分区间，缺少 Enabled 时不伪造模式。
- 平均功率在日志包含 `Enabled` 序列时仅统计选区内 Enabled 区间的能量与时长；全 Disabled 返回 0，缺少 `Enabled` 时回退到完整选区。总能量、占比、峰值与调和结果仍按完整选区计算。
- 独立“模拟”页提供多目标 Supply Current 历史反事实回放：唯一合法目标是 V2 Manifest 中的一台 Leader 与其全部直接 Followers，包括 V2.4 supply-only 组；输入值是该电机组合计 Supply Current 上限，不是单个控制器限流。Follower 不生成独立目标，多个合法电机组天然互不重叠，只拒绝重复目标。V1 因没有 Manifest 必须明确显示不可用，不得回退到 canonical 子系统节点猜测电机组。编辑器平铺 `子系统/Leader`，仅在存在 Followers 时于次行列出名称；每行在原指标右侧直接预填限流值并独立启用。配置只有一份稀疏实时状态，开启后有效修改立即原子重算；正向电流、功率和输入能量按 sample-and-hold 比例缩放，负值与不完整成员区间不编造扣减；canonical 峰值只在 robot 时间轴计算 residual，平均功率沿用 Enabled-only 口径。该模型不预测 Stator Current、电池电压、Brownout、机构动作或动作耗时。
